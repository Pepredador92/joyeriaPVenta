# CHECKLIST_SMOKE.md

## Smoke Checklist
- [ ] Ventas: crear una venta y verificar que descuenta stock.
- [ ] Productos: CRUD completo (crear, leer, actualizar, eliminar).
- [ ] Clientes: CRUD completo (crear, leer, actualizar, eliminar).
- [ ] Corte de caja: abrir, cerrar y exportar.
- [ ] Reportes: filtrar y exportar.
- [ ] Dashboard: carga de KPIs.
- [ ] Settings: guarda y carga correctamente.
